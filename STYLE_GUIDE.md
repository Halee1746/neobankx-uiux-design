# NeoBank X - Style Guide

## Colors

* Primary Blue: #2563EB
* Success Green: #22C55E
* Error Red: #EF4444

## Typography

* H1: 32px Bold
* H2: 24px Bold
* Body Text: 16px Regular

## Components

* Buttons
* Inputs
* Cards
* Bottom Navigation

## Spacing System

* 8px
* 16px
* 24px

## Usage Rules

* Use Blue for primary actions.
* Use Green for success states.
* Use Red for error messages.
* Maintain consistent spacing throughout the application.
* Use reusable components wherever possible.
